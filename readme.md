# Kom ihåg 

## HTML

* Står för HyperText Markup Language
* Används för att strukturera information
* En html-fil måste innehålla `<html></html>`, `<head></head>` och `<body></body>`
* `<head></head>` innehåller information om sidan till webbläsaren (metadata)
* `<body></body>` innehåller det som visas på sidan för läsaren
